# SoundRevive site

Minimal Next.js frontend for the SoundRevive research benchmark. Currently a single home page
reporting the STANDARD-tier speaker-held-out generalization finding (see the repo root's
`docs/HANDOFF.md` and `research/claims_registry.md` row C6). Every number on the page comes
from `app/data/summary.json`, generated by `../scripts/generate_site_summary.py` from the
checked-in `results/standard/*.parquet` artifacts — never hand-typed (see the project's own
claims-registry rule).

The rest of the site (brief §41's `/benchmark`, `/listen`, `/degradations`, `/methods`,
`/fidelity`, `/hallucination`, `/historical`, `/study`, `/research-methods`, `/paper` routes)
is not built yet.

## Develop

```bash
npm install
npm run dev       # http://localhost:3000
```

Regenerate `app/data/summary.json` after a new benchmark run:

```bash
cd .. && source .venv/bin/activate && python scripts/generate_site_summary.py
```

## Build

```bash
npm run build
```
